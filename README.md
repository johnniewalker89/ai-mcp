# ai-mcp

Публичные MCP-серверы для совместного использования.

## Пакеты

| Пакет | Назначение |
| --- | --- |
| [`mcp-metabase`](mcp-metabase/README.md) | Работа с карточками, дашбордами, коллекциями и полями Metabase через компактный typed API |

## Установка

Пакеты устанавливаются напрямую из Git через [`uvx`](https://docs.astral.sh/uv/).
Используй точный commit SHA, чтобы обновление репозитория не меняло установленный
runtime неожиданно.

Команда установки, переменные окружения, полный список tools и правила безопасности
приведены в README выбранного пакета.

Секреты хранятся только в локальном MCP-конфиге или окружении и никогда не добавляются
в репозиторий.
